# Руководство по кодовой базе

Это практическая карта проекта: с чего начать чтение, где искать разные части клиента и какие соглашения снижают риск регрессий.

## Поток запуска

1. Fabric вызывает `platform.Initializer` из `fabric.mod.json`.
2. `Initializer.onInitializeClient()` создаёт основной объект `aethereal.core.Primordial`.
3. `aethereal.core` связывает клиентские сервисы, регистрацию модулей и события. Начните изучение с `Primordial.java`, затем проследите регистрацию в `ModuleRegister.java` и публикацию/подписку в `EventManager.java`.
4. Mixin-конфигурация `primordial.mixins.json` подключает классы из `platform.inject.mixin`. Эти классы встраиваются в Minecraft и часто служат мостом от игровых методов к событиям и функциям клиента.

## Карта пакетов

| Путь | Назначение |
| --- | --- |
| `aethereal/core` | Жизненный цикл клиента, модулей и событий |
| `aethereal/module/{combat,misc,movement,player,render}` | Игровые модули, сгруппированные по категории |
| `aethereal/setting` | Базовый класс и типы настроек |
| `aethereal/event` | Типы событий |
| `aethereal/handler` | Состояние и обработчики игровых подсистем |
| `aethereal/config` | Сериализация, преобразования и конфигурационные процессоры |
| `aethereal/ui` | Экраны, виджеты, шейдеры и компоненты интерфейса |
| `aethereal/render` | Рендер-компоненты вне экранов интерфейса |
| `aethereal/network` | Сетевые компоненты клиента |
| `aethereal/util` | Общие небольшие утилиты |
| `aethereal/lib` | Встроенные или адаптированные сторонние компоненты |
| `platform/inject/mixin` | Mixin-инъекции в Minecraft |
| `platform/inject/accessors` | Mixin accessors и invokers для доступа к Minecraft API |
| `platform/inject/invokers` | Явно объявленные вызовы закрытых/недоступных методов |

## Как проследить одну функцию

Для примера выберите модуль в `aethereal/module`, найдите его регистрацию через поиск по имени класса в `ModuleRegister`, затем найдите обработчики событий модуля через `@EventTarget`. Если событие приходит из Minecraft, найдите соответствующую публикацию в `aethereal/event` или `platform/inject/mixin`. Настройки модуля обычно объявлены рядом с логикой модуля и используют типы из `aethereal/setting`.

Полезные поиски из корня проекта:

```powershell
rg -n "class ModuleRegister|register\(" src/main/java/aethereal/core src/main/java/aethereal/module
rg -n "@EventTarget|post\(" src/main/java/aethereal src/main/java/platform/inject
rg -n "@Inject|@Redirect|@Modify" src/main/java/platform/inject/mixin
```

## Соглашения для изменений

- Используйте описательные имена для новых классов, методов, локальных переменных и параметров: `targetEntity`, `cooldownTicks`, `isEnabled`.
- Сохраняйте имена публичных методов и полей, если на них опираются конфиги, reflection, JSON или другие модули. Перед переименованием ищите все использования.
- В Mixin-классах не переименовывайте поля и методы целевого Minecraft-класса без проверки аннотаций, дескрипторов, refmap и Mixin-конфигурации. Имя метода в `@At(target = "...")` — строковая ссылка, IDE может не найти её как обычный вызов.
- Делайте небольшие изменения с одной понятной целью. Особенно осторожно меняйте порядок вызовов событий, сетевых пакетов и инвентарных операций.
- Не перемещайте классы между пакетами без обновления строковых ссылок: `fabric.mod.json`, `primordial.mixins.json`, рефлексии, ресурсов и конфигураций.
- Удаляйте импорт только после проверки компиляции: часть кода использует наследуемые типы, static import и аннотационные процессоры.

## Сборка

Проект рассчитан на Java 21 и Minecraft 1.21.4. В Windows:

```powershell
java -version
.\gradlew.bat build
```

Выходной игровой мод — `build/libs/primordial-1.0.0.jar`. JAR с суффиксом `-sources` содержит исходный код. Gradle может скачать wrapper, Minecraft и зависимости при первой сборке, поэтому первый запуск заметно медленнее последующих.

## Безопасная последовательность рефакторинга

1. Начните с локальных имён и форматирования внутри одного обычного класса.
2. Для перемещений или переименований обновите все Java-ссылки и строковые конфигурации.
3. После изменений Mixin проверьте сборку и запуск на целевой версии Minecraft: успешной компиляции недостаточно, чтобы подтвердить корректность точки инъекции.
4. Для изменений поведения сравните соответствующий сценарий в игре до и после правки.
